## 📊 Project Overview
The **Farmers Market Dashboard** is an interactive Power BI dashboard designed to analyze and visualize sales and customer data from farmers markets. It provides insights into product quantities, vendor performance, customer distribution, and booth utilization.

## 🧠 Key Insights
- Displays total quantity sold per product category.
- Tracks vendor and booth performance using KPIs.
- Visualizes customer distribution across different regions.
- Provides real-time analytics through interactive charts and maps.

## 🛠️ Tools & Technologies
- **Power BI Desktop**
- **Microsoft Excel / CSV** for data source
- **Data Modeling** using DAX and relationships
- **Visualization Techniques** (Pie Charts, Bar Graphs, Map Visuals, KPIs)

## 📈 Dashboard Features
- **Sum of Quantity by Product Name:** Highlights product sales contribution.
- **Customer Distribution Map:** Shows geographical spread of customers.
- **Total Quantity by Product ID:** Compares sales volumes per product.
- **KPI Cards:** Display total quantity, number of vendors, booths, and customers.
- **Interactive Filters:** Allow users to slice data dynamically.

## 🎯 Objective
To create a visually appealing and data-driven dashboard that helps market organizers and vendors make informed decisions, improve inventory planning, and understand customer behavior better.
